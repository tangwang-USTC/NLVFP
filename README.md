# NLVFP

Project home for the three-space, three-velocity (3D3V) nonlinear Vlasov–Fokker–Planck model line.

## Model-specific repositories

- [NLVFP0D1V](https://github.com/tangwang-USTC/NLVFP0D1V) — homogeneous, isotropic radial 0D1V Julia solver and its verified 0.0.1 baseline.
- [NLVFP1D2V](https://github.com/tangwang-USTC/NLVFP1D2V) — separate one-space, two-velocity (1D2V) project.

## Historical implementation

The solver and the earlier baseline below are 0D1V. This historical material covers the radial 0D1V model. 3D3V names the current project scope.
